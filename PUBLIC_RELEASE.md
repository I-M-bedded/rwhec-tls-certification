# Public release notes

This export starts without the development repository history. Numerical inputs,
images, robot measurements, solver code and upstream licenses are retained.
Historical `/home/bae/` prefixes in JSON metadata are replaced with
`source-records/`; these are provenance labels, not runtime paths. The release
SHA256 manifest is regenerated for this export. No solver algorithm is changed.
The public package reproduces the real 44-observation experiment; the paper's
synthetic experiments are not included in the upstream release.

The project page lives in `docs/` and can be served by GitHub Pages.
Configure Pages to deploy from the main branch, /docs folder.
